The scanner pins the framework at Next.js 14.2.0. That release carries CVE-2025-29927, an authorization bypass in the middleware layer ( https://github.com/UNICORDev/exploit-CVE-2025-29927). Next.js relies on the internal `x-middleware-subrequest` header to stop middleware from re-invoking itself, so a request that already carries that header skips middleware entirely. The login gate and route protection live in that middleware, which means forging the header walks straight past the auth check.
